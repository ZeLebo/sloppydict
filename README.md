# SloppyDict

Диктуйте текст в другие приложения, удерживая сочетание клавиш или включая запись повторным нажатием. SloppyDict распознаёт речь на самом Mac и копирует результат в буфер обмена или вставляет в исходное поле. Во время записи видна небольшая плашка с таймером; открывать настройки для получения текста не нужно.

**[Скачать для macOS](https://github.com/ZeLebo/sloppydict/releases)** · macOS 14 или новее · Apple Silicon (arm64).

Распознавание работает через Parakeet Ultra и FluidAudio. Core ML настроен на CPU и Neural Engine; препроцессор работает на CPU, распределение остальных операций определяет Core ML. Подписка и облачный сервис не нужны.

## Установка

1. Скачайте `SloppyDict-v0.1.0-macos-arm64.zip` со страницы релизов, распакуйте и перенесите `SloppyDict.app` в «Программы».
2. Откройте приложение. Оно появляется в строке меню; настройки доступны через иконку микрофона.
3. Нажмите «Загрузить и подготовить модель». Нужен интернет и около 630 МБ на диске. Первая подготовка Core ML может занять время.
4. Разрешите доступ к микрофону. Для режима автоматической вставки также разрешите «Универсальный доступ». Нажмите «Проверить доступ»; при необходимости перезапустите приложение.
5. Выберите язык и способ выдачи результата, поставьте курсор в текстовое поле и начните диктовку.

Предварительная сборка использует **ad hoc подпись, без Apple Developer ID и нотариализации Apple**. macOS может заблокировать первый запуск. Если вы доверяете скачанному файлу, используйте разрешение для конкретного приложения в «Системные настройки → Конфиденциальность и безопасность», как описано в [инструкции Apple](https://support.apple.com/en-us/102445). Смена подписи или расположения приложения может потребовать повторной выдачи разрешений.

Рядом с ZIP опубликован файл `.sha256`. Для проверки скачанных файлов выполните в их каталоге:

```sh
shasum -a 256 -c SloppyDict-v0.1.0-macos-arm64.zip.sha256
```

## Использование

| Действие | Сочетание по умолчанию |
| --- | --- |
| Записывать при удержании | Control + Space |
| Начать / закончить запись | Control + Option + Space |
| Отменить диктовку | Esc |

Оба сочетания записи настраиваются независимо. Если сочетание занято macOS или другим приложением, выберите другое. Обычный Space без модификатора не поддерживается. Одна запись ограничена двумя минутами, после чего автоматически начинается распознавание.

Доступны русский, English, выбор по текущей раскладке RU/EN и экспериментальная смешанная речь. Раскладка фиксируется в начале записи. Если её язык неизвестен, выберите русский или English вручную. Качество смешанной речи зависит от произношения и контекста.

Модель сама добавляет регистр и пунктуацию. Отдельного переписывания текста нет; запятые и другие знаки могут требовать исправления, особенно в длинной или смешанной речи.

Результат всегда остаётся в системном буфере обмена. Режим «Вставлять в исходное поле» дополнительно отправляет Command + V, без Enter. При смене фокуса, недоступном или защищённом поле автоматическая вставка не выполняется: плашка сообщает об этом, а текст можно вставить вручную. Режим «Только копировать в буфер» не требует Универсального доступа.

## Приватность

Аудио обрабатывается в памяти и не сохраняется. Истории диктовок нет: последний результат хранится в памяти приложения до следующей записи или выхода. Копия текста остаётся в системном буфере до следующего копирования и может быть доступна менеджерам буфера обмена.

Сеть используется для явной загрузки модели из Hugging Face. После загрузки распознавание работает локально, сетевые загрузки FluidAudio отключены. Модель хранится в `~/Library/Application Support/SloppyDict/Models/` и в скачиваемую сборку не входит.

Глобальные сочетания регистрируются через `RegisterEventHotKey`. Глобального фильтрующего перехвата клавиатуры нет. Esc регистрируется только на время записи или распознавания.

## Сборка из исходников

Нужны Mac с Apple Silicon, macOS 14+, Command Line Tools со Swift 6.2+ и интернет для первой загрузки зависимости.

```sh
make build
```

Приложение будет в `build/SloppyDict.app`. Для создания отдельного архива с ad hoc подписью и контрольной суммой:

```sh
make package
```

Архив появляется в `build/`. При упаковке локальные пути компиляции заменяются, отладочная информация удаляется. Версия берётся из `Resources/Info.plist`. Лицензии включённых зависимостей копируются внутрь приложения.

## Проверки

```sh
make test
make check
```

`make test` проверяет переходы записи, преобразование модификаторов, очередь событий и состав исходников. Тесты не регистрируют системные шорткаты, не публикуют события и не обращаются к микрофону, буферу или окнам. Они не подтверждают поведение реальной клавиатуры, микрофона или вставки.

Отдельная ручная цель `make test-native` проверяет выдачу текста через тестовый pasteboard. Она обращается к системному сервису буфера, но не отправляет клавиши и не входит в обычный `make test`.

Для проверки модели на аудиофайле без микрофона:

```sh
build/SloppyDict.app/Contents/MacOS/SloppyDict --prepare-model .local/models
build/SloppyDict.app/Contents/MacOS/SloppyDict --transcribe .local/models sample.wav
```

Команда транскрипции выполняет два прохода и выводит текст и длительность каждого. Эти команды не используют микрофон и не вставляют текст в другие приложения.

`make check` рассматривает рабочие файлы, индекс и историю локальных веток/тегов: отклоняет личные абсолютные пути, известные форматы секретов, симлинки и бинарные файлы. Это набор конкретных проверок, а не гарантия отсутствия любых персональных данных. Состав публикации нужно просмотреть перед отправкой. Зависимости, модель, результаты сборки и локальные рабочие заметки исключены через `.gitignore`; `Package.resolved` сохраняется.

`make hooks` подключает ту же проверку к pre-commit и pre-push в текущем репозитории. Настройка локальная; после нового клонирования команду нужно выполнить заново.
